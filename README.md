# Wikiart Image Classification

## Overview
This Project researches Deep Learning methods for classifying paintings by artists using modified subset of the "wikiart" dataset.

## Project Goal
Build and evaluate an image classification model capable of predicting the painter of an artwork from its image.

## Files available in this repository:
- wikiart: raw image dataset
- eda: notebook for preprocessing, exploration, and data split
- model_scratch: notebook for the CNN model built from scratch
- pre_trained: notebook for transfer learning and pre-trained model training.
